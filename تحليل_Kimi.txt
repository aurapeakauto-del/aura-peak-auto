# تقرير تحليل مشروع Next.js - Aura Peak Auto

## ملخص تنفيذي

هذا المشروع هو متجر إلكتروني لإكسسوارات السيارات الفاخرة مبني بـ Next.js 16 مع Supabase كقاعدة بيانات. يحتوي المشروع على العديد من الأخطاء الحرجة ومشاكل الجودة التي تتطلب اهتماماً فورياً.

---

## 🔴 الأخطاء الحرجة (Critical Errors)

### 1. إنشاء عميل Supabase مباشر في API Route بدون التحقق من البيئة
**الملف:** `app/api/keep-alive/route.ts`

```typescript
// ❌ خطأ: استخدام مفاتيح عميل (anon) في الخادم بدلاً من مفاتيح الخدمة (service role)
const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const supabaseKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!;
const supabase = createClient(supabaseUrl, supabaseKey);
```

**المشكلة:** يستخدم `NEXT_PUBLIC_SUPABASE_ANON_KEY` في API Route، وهذا مفتاح عميل يفتقر إلى صلاحيات الكتابة/الحذف المطلوبة للعمليات الإدارية. يجب استخدام `SUPABASE_SERVICE_ROLE_KEY` في الخادم.

### 2. استخدام `window` و `navigator` بدون التحقق من البيئة
**الملف:** `app/admin/login/page.tsx`

```typescript
// ❌ خطأ: window.location.replace يعمل فقط في المتصفح
window.location.replace('/admin');
```

**المشكلة:** `window.location.replace` يُستخدم في مكون عميل، لكن Next.js قد يُجري render أولي على الخادم. يجب استخدام `router.replace()` من `next/navigation` بدلاً من ذلك.

### 3. خطأ في معالجة الـ params في Next.js 15+
**الملف:** `app/products/[id]/page.tsx`

```typescript
// ❌ خطأ: params يجب أن يكون Promise في Next.js 15+
type tParams = Promise<{ id: string }>
export default async function ProductDetailsPage(props: { params: tParams }) {
  const { id } = await props.params  // صحيح
```

**ملاحظة:** الرمز `✅` في التعليق يوحي بأن هذا صحيح، لكن في Next.js 15+، `params` يجب أن يُعالج بشكل مختلف. التصحيح الموجود يعمل، لكن التعليقات المربكة قد تسبب مشاكل في الصيانة.

### 4. استخدام `img` بدلاً من `Image` من Next.js
**الملفات:** `app/components/ProductCard.tsx`, `app/products/[id]/ProductDetailsClient.tsx`, `app/admin/page.tsx`

```typescript
// ❌ في ProductCard.tsx وغيره
<img src={product.image} alt={product.name} className="..." />
```

**المشكلة:** استخدام `<img>` بدلاً من `<Image>` من `next/image` يفقد:
- التحميل التلقائي (lazy loading)
- التحسين التلقائي للصور
- منع تخطيط التحول (layout shift)

### 5. خطأ في إدارة المخزون مع المتغيرات
**الملف:** `app/lib/products.ts`

```typescript
// ❌ خطأ منطقي: المخزون الأساسي يُجمع مع مخزون المتغيرات
const totalStock = parseInt(formData.stock) + variantsStock + fitmentsStock;
```

**المشكلة:** في `handleSubmit` في `app/admin/page.tsx`، المخزون الأساسي يُضاف إلى مخزون المتغيرات، مما يؤدي إلى تضخيم المخزون. المخزون الأساسي يجب أن يكون مستقلاً أو يُحسب بطريقة مختلفة.

## 📋 التحسينات المقترحة

### تحسينات هيكلية

| الأولوية | الملف/المنطقة | التحسين | التأثير |
|---------|-------------|---------|--------|
| عالية | `app/admin/page.tsx` | تقسيم إلى مكونات أصغر | صيانة أسهل، أداء أفضل |
| عالية | `app/lib/products.ts` | إضافة TypeScript interfaces صارمة | أقل أخطاء وقت التشغيل |
| متوسطة | `app/api/keep-alive/route.ts` | إضافة Rate Limiting | أمان أفضل |
| متوسطة | جميع الملفات | استبدال `any` بأنواع صحيحة | جودة الكود |

### تحسينات الأداء

```typescript
// ✅ في next.config.ts
const nextConfig: NextConfig = {
    reactStrictMode: true, // تفعيل
    images: {
        domains: ['res.cloudinary.com'],
        // إضافة optimization
        formats: ['image/webp', 'image/avif'],
    },
    // إضافة caching
    async headers() {
        return [
            {
                source: '/api/:path*',
                headers: [
                    { key: 'Cache-Control', value: 's-maxage=60, stale-while-revalidate' }
                ]
            }
        ];
    }
}
```

### تحسينات الأمان

```typescript
// ✅ في app/api/keep-alive/route.ts
import { rateLimit } from '@/app/lib/rate-limit';

const limiter = rateLimit({
    interval: 60 * 1000, // 1 minute
    uniqueTokenPerInterval: 500
});

export async function GET(request: Request) {
    try {
        await limiter.check(request, 10, 'CACHE_TOKEN'); // 10 requests per minute
        // ...
    } catch {
        return NextResponse.json({ error: 'Rate limit exceeded' }, { status: 429 });
    }
}
```
